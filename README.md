
# ⚡ Cyberpunk Login Page

A futuristic, responsive, and visually captivating login page built with **HTML**, **CSS**, and **JavaScript**. Designed with attention to user experience, accessibility, and dynamic interactivity, this project showcases a clean structure, glowing UI, and smooth animations inspired by cyberpunk aesthetics.

## ✨ Features

- 🔐 **Modern Login Form**  
  Clean, floating-label form with username/password fields and a stylish password toggle feature.

- 🧠 **Interactive UI**  
  Custom JavaScript adds a glowing grid animation that responds to user interaction in real-time.

- 🌌 **Cyberpunk-Inspired Design**  
  Uses a neon color palette, glowing effects, and custom typography (`Cyberpunk Is Not Dead` font) to create an immersive interface.

- 📱 **Fully Responsive**  
  Designed to work seamlessly across all devices and screen sizes using responsive CSS media queries.

- 🕶️ **Accessible & User-Friendly**
  Includes accessible labels, placeholders, and focus states for enhanced usability.

## 🚀 Technologies Used

- **HTML5** — semantic layout & structure  
- **CSS3** — responsive layout, animations, media queries, and custom design  
- **JavaScript** — interactive behavior for password toggle and animated background grid

## 🎯 Use Case
